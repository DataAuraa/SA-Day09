Module 1: The Paradigm Shift

Traditional AI Learns to Predict. GenAI Learns to Create.

Traditional Machine Learning models learn mathematical mappings from historical structured datasets to produce a deterministic prediction or label (e.g., student marks → Pass/Fail, email → Spam/Not Spam, credit card transaction → Fraud/Genuine).

In contrast, Generative AI can synthesize entirely novel artifacts based on user instructions and patterns learned from vast corpuses—generating original text, executable code, synthesized audio, photorealistic graphics, or structured JSON.

// The AI Hierarchy (Section 6)
ARTIFICIAL INTELLIGENCE
└ Rule-Based AI / Expert Systems
├ MACHINE LEARNING
├ DEEP LEARNING (Neural Networks)
├ GENERATIVE AI

└ Diffusion Models (Image, Video, Audio)

Module 2: Large Language Models

A General-Purpose Statistical Language Engine

An LLM is a deep neural network trained on massive datasets of text and code to learn statistical patterns in language and generate coherent completions based on input context.

Critical Distinction: LLM != "Human Brain"

Students often assume ChatGPT possesses conscious reasoning or omniscience. Remind them: An LLM processes tokens via matrix multiplications, computes attention weights, and samples probable token continuations. Fluent language does NOT guarantee factual accuracy!

Why LLMs Changed the Industry

Previously, companies required separate isolated models for Sentiment, Translation, Entity Extraction, and Summarization. One LLM performs all four via distinct prompt instructions!

Statistical Continuation Sandbox

LLMs predict the most statistically probable next token based on learned representations:

Prompt: "Python is a programming ______"
→ "language" (Probability: 94.8%)
Complex Prompt: "Extract technical skills from: Python developer with 3 years experience in Pandas, SQL and ML"
→ ["Python", "Pandas", "SQL", "Machine Learning"]
Module 3: Transformer Engine & Self-Attention

Why Transformers Revolutionized AI

Vaswani et al. (2017) "Attention Is All You Need"

Older sequence architectures like RNNs (Recurrent Neural Networks) processed sentences strictly token-by-token (Word 1 → Word 2 → Word 3). As sequences grew, earlier context was forgotten, and parallelization on modern GPUs was impossible.

Transformers process entire sequences simultaneously, computing pairwise dynamic relationship weights via Self-Attention. Each token attends to all other tokens to construct context-aware contextual embeddings.

Scaled Dot-Product Attention Formula
$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

Query (Q): What the current token is seeking • Key (K): What other tokens offer • Value (V): The actual token representations weighted by attention score.

Interactive Self-Attention Resolving

Click on the pronoun "she" to inspect attention weights:

Anjali submitted her resume because she wanted a job.
she → Anjali 0.86 (Highest Attention)
she → resume 0.08
she → job 0.06
Trainer Takeaway: Self-attention allows each token to consider all tokens in the same sequence, determining who "she" refers to without handcrafted grammatical rules.
Module 4: Tokens & The Context Window

Characters ≠ Words ≠ Tokens

Rule of Thumb: 1 token ≈ 4 characters (≈ 0.75 words) in English
Tokenized Chunks:
Characters 56
Words 6
Tokens 9

Context Window != Long-Term Memory

The context window is the finite token envelope an LLM holds simultaneously for a single request:

[ System Instructions ] +
[ User Prompt ] +
[ Full Candidate Resume ] +
[ Job Description ] +
[ Output Tokens Requested ]
= Total Context Utilization (Must fit limit!)
Why it matters for HR: A 20-page resume booklet with 10 past projects will consume high tokens, increasing API costs and latency.
Module 5: Responsible AI & Hallucination Mitigation

High-Impact Decisions Require Human Oversight

Golden Rule: AI Assists, Humans Decide

What is Hallucination?

Hallucination occurs when an AI generates confident, plausible-sounding claims that are completely unsupported by the provided document.

Resume states:

"Python, SQL, Pandas. 1 year as Junior Analyst."

Hallucinated Response (Severe Risk)

"The candidate is an expert AWS Cloud Architect with 5 years leading Kubernetes deployments." ← Fabricated!

Evidence-Based Grounded Response

"Cloud experience is not mentioned in the provided resume. Matched skills: Python, SQL, Pandas."

Trainer Checklist: 8 Ways to Reduce Hallucinations
Restrict context source
"Do not invent info" rule
Require explicit quotes
Enforce JSON schemas
Fallback to null/empty
Use deterministic code for math
Synthetic test resumes
Final human approval

Recruitment Ethics & Compliance

Never Build: AI → Automatically Reject Candidate

Automated rejection systems risk unlawful demographic bias, proxy discrimination, and false negative skill extractions.

The Approved Enterprise Pattern
Candidate Resume AI Synthesizes Skill Overlap & Gaps Presents Evidence & Interview Questions Human HR Recruiter Makes Final Decision

Privacy Note: Resumes contain Personally Identifiable Information (PII) like phone numbers and addresses. Always sanitize or use synthetic mock profiles in public AI notebooks.

Practical Core Skill

Prompt Engineering Framework

The mathematical 5-part architecture to transform vague, ambiguous instructions into deterministic, high-accuracy enterprise outputs.

PART 1
ROLE

Who the LLM acts as ("You are an AI HR Assistant")

PART 2
TASK

Exact actions ("Extract technical skills & compare with JD")

PART 3
CONTEXT

Background data ("Candidate applying for Data Scientist")

PART 4
CONSTRAINTS

Guardrails ("Do not invent skills; use only provided text")

PART 5
OUTPUT FORMAT

Machine structure ("Return strictly valid JSON with keys...")

The Evolution of Prompt Quality (Section 23) Live Classroom Progression
POOR PROMPT Fails in Production
"Analyze this resume."
  • • No role context or candidate persona
  • • Unknown target job specification
  • • Vague prose output cannot be parsed by code
  • • High hallucination probability
BETTER PROMPT Partial Specifics
"Analyze the following resume and identify the candidate's technical skills, databases, and ML experience."
  • • Clearer task specifications
  • • Still lacks guardrails against inventing skills
  • • Unstructured paragraphs still break software integration
ENTERPRISE GRADE ✓ Recommended 
You are an AI HR Assistant.
Analyze candidate resume against Data Scientist JD.
Extract: 1. Languages 2. Frameworks 3. Experience 4. Missing skills.
CONSTRAINTS: Do not assume missing skills. Use only explicit text.
OUTPUT: Return strictly valid JSON containing {skills, experience, matched, missing, questions}.
  • • Complete 5-part framework implemented
  • • Zero hallucination guarantee clause
  • • Deterministic JSON for Python json.loads()

Zero-Shot Prompting

0 Examples

The model relies exclusively on pre-trained internal weights and instruction guidelines without reference input/output pairs.

# Instruction only:
Extract technical skills from: "Python developer with Django and SQL."

Few-Shot Prompting

2+ Exemplars

Provides the LLM with 1–3 explicit demonstration input/output pairs to establish an exact response syntax and entity categorization pattern.

# Example 1:
Input: "Python, SQL and Pandas" → {"skills": ["Python", "SQL", "Pandas"]}
# Example 2:
Input: "Java, Spring Boot, MySQL" → {"skills": ["Java", "Spring Boot", "MySQL"]}
# Now complete:
Input: "Python, TensorFlow, SQL and AWS" → ...

# Practical 3 & 4: Skill Matching & Match Percentage without an LLM (Sections 22, 23 & 49)
# Connects Day 07 Python fundamentals with GenAI workflows

candidate_skills = {
    "Python",
    "SQL",
    "Pandas",
    "Machine Learning",
    "Power BI"
}

job_skills = {
    "Python",
    "SQL",
    "Pandas",
    "Machine Learning",
    "Scikit-learn",
    "Statistics",
    "Power BI"
}

# 1. Deterministic Set Operations (Zero Token Cost!)
matched_skills = candidate_skills.intersection(job_skills)
missing_skills = job_skills.difference(candidate_skills)

# 2. Percentage Calculation
match_percentage = (len(matched_skills) / len(job_skills)) * 100

print(f"Matched Skills: {matched_skills}")
print(f"Missing Skills: {missing_skills}")
print(f"Match Percentage: {match_percentage:.2f}%")

# Important Classroom Note:
# Use Python for deterministic calculations and set math;
# Use the LLM for entity extraction, unstructured parsing, and reasoning!

Chapter 02

Foundational Concepts & Transformer Mechanics

Traditional AI vs Generative AI

Traditional AI/ML learns patterns from historical datasets to produce fixed classifications or numerical predictions (e.g., student marks → Pass/Fail, transaction → Fraud/Genuine). Generative AI can synthesize entirely novel artifacts based on user instructions and context—producing natural text, executable code, or structured JSON.

Why Transformers Over RNNs?

Older recurrent architectures processed sequences sequentially token-by-token. Transformers process sequences concurrently using Self-Attention, capturing bidirectional dependencies across the entire sequence.

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

Query (Q): What the token seeks • Key (K): What other tokens offer • Value (V): Information payload.

Tokens & Context Windows

LLMs do not perceive words directly; text is decomposed into subword tokens. A token is approximately 4 characters or 0.75 English words. Tokens dictate API expenditure, processing latency, and maximum context utilization.

Chapter 04

Complete Python Implementation Code

Deterministic Skill Matching via Python Sets:

candidate_skills = {"Python", "SQL", "Pandas", "Machine Learning", "Power BI"}
job_skills = {"Python", "SQL", "Pandas", "Machine Learning", "Scikit-learn", "Statistics", "Power BI"}

# 1. Deterministic Set Operations (Zero Token Cost)
matched = candidate_skills.intersection(job_skills)
missing = job_skills.difference(candidate_skills)

# 2. Percentage Overlap
match_percentage = (len(matched) / len(job_skills)) * 100
print(f"Matched Skills: {matched}")
print(f"Missing Gaps:   {missing}")
print(f"Match Score:    {match_percentage:.2f}%")

Key Interview Questions:

Q1. What is the fundamental difference between Traditional AI and Generative AI?

Traditional AI maps inputs to fixed historical categories (predictive/discriminative), whereas Generative AI synthesizes novel content (text, code, structured JSON) conditioned on prompt instructions.

Q2. Why should recruitment applications NEVER automatically reject candidates using an AI score?

Employment decisions carry severe legal and ethical ramifications. AI models can inherit historical bias, misinterpret non-standard resume formats, or hallucinate missing skills. AI must assist human HR recruiters, never replace them.

Q3. Why combine deterministic Python with an LLM rather than asking the LLM to do everything?

LLMs are probabilistic and unreliable at exact mathematics and strict set operations. Python executes set intersections and percentage scores with 100% precision at zero token cost, while the LLM excels at unstructured parsing and reasoning.
